# Amber for Mobile

iOS & Android app — capture and recall links on the go, share-sheet integration, optional Firebase sync. Flutter/Dart, Firebase, SQLite. UI strings are in Italian.

See the [root README](../README.md) for the full feature list, data model, and Firebase setup shared across all Amber clients.

## Requirements

- Flutter 3.x, Dart 3.x
- Android SDK / Xcode (for iOS)
- Java 17+ for Android builds (`brew install openjdk@17`, set `JAVA_HOME`)

## Setup

```bash
cp env.example.json env.json   # fill in your Firebase config
flutter pub get
flutter run --dart-define-from-file=env.json
```

## Commands

```bash
flutter build apk --dart-define-from-file=env.json   # Android release
flutter build ios --dart-define-from-file=env.json    # iOS release
flutter test                                            # run all tests
flutter test test/widget_test.dart                      # single test file
flutter analyze                                          # lint
```

## Architecture

- **State:** `provider` (ChangeNotifier) — `AuthProvider` wraps Firebase Auth, `LinkProvider` manages the links list via `LinkRepository`.
- **Repository pattern:** `LinkRepository` routes to `FirebaseStorageService` (Firestore, logged in) or `LocalStorageService` (SQLite `amber.db`, logged out). Login migrates local links to Firestore and clears the local DB.
- **Share intent:** app registers as a share target — `receive_sharing_intent` extracts URLs and opens `AddLinkScreen` pre-filled.
- **Firebase config:** `lib/firebase_options.dart` (generated by `flutterfire configure`).
