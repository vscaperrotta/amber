## Architecture

**Amber** is a link-saving app (like Pocket) with optional Firebase sync. UI strings are in Italian. See [`MAP.md`](MAP.md) for the full source tree, SQLite schema, and data-flow diagrams.

### State Management
Uses `provider` (ChangeNotifier pattern). Four providers:
- `AuthProvider` — wraps Firebase Auth, exposes `user`, `isLoggedIn`, auth methods
- `LinkProvider` — manages the links list, delegates to `LinkRepository`
- `CollectionProvider` — manages collections (folders), delegates to `CollectionRepository`
- `UiStateProvider` — UI toggles (grid/list view, active tab, filter state)

### Repository Pattern (key abstraction)
Two repositories route storage calls based on auth state:
- `LinkRepository` — links: logged in → `FirebaseStorageService` (Firestore: `/users/{uid}/links/{linkId}`); logged out → `LocalStorageService` (SQLite: `amber.db`)
- `CollectionRepository` — collections: same auth-based routing to Firestore `/users/{uid}/collections` or the SQLite `collections` table

On login, `migrateLocalToCloud()` moves all local SQLite links to Firestore and clears the local DB.

### Data Models
- **`LinkItem`** — `id` (UUID v4), `url`, `title`, `tags` (List<String>, stored/displayed UPPERCASE), `createdAt`, `isFavorite`, `isRead`, `thumbnail?`, `note?`, `collectionId?`. `fromMap()` handles two date formats (ISO 8601 string and millisecond timestamp) and reads metadata from either the flat SQLite columns or the nested Firestore `metadata` map.
- **`CollectionItem`** — `id` (UUID v4), `name`, `parentId?`, `color?`, `createdAt`. Represents a folder that can group links.
- **`LinkFilter`** — combined filter state for the Home list: `collectionId?`, `unreadOnly`, `tags` (Set<String>); applied together via `isActive`/`activeCount`.

### Metadata Fetching
`MetadataService.fetchMetadata(url)` does an HTTP GET, parses the HTML with the `html` package, and extracts `og:title` → `<title>` → hostname for the title, and `og:image` → `twitter:image` for the thumbnail. Relative image URLs are resolved against the page URI. Used by `AddLinkScreen` to pre-fill title and thumbnail when saving a link.

### Share Intent
The app registers as a share target. `main.dart` sets up a global navigator key and a `receive_sharing_intent` listener that extracts URLs via regex and navigates to `AddLinkScreen` with a pre-filled URL.

### Firebase
Credentials are in `lib/firebase_options.dart` (generated by `flutterfire configure` — replace with your own project). Firestore security rules need to be deployed separately.

### Theme & Fonts
Design system is Void v2 (see [`../DESIGN.md`](../DESIGN.md)). Colors live in `lib/theme/void_colors.dart`; semantic aliases in `lib/theme/app_colors.dart`. Fonts are **bundled locally** in `assets/fonts/` (no network fetch): **Mulish** for body/UI text, **Baloo2** for large display headings (`AppFonts.body()` / `AppFonts.display()` in `lib/theme/app_fonts.dart`). App icon font is **CoolIcons** (`lib/theme/cool_icons.dart`).
